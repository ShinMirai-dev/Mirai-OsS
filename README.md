# Mirai-OsS
Mirai OS

Mirai OS is an experimental operating system project built from the ground up as a learning and development project. The project explores operating-system concepts, low-level programming, system architecture, and the process of building a custom OS environment.

The project was developed using WSL (Windows Subsystem for Linux) with Ubuntu as the development environment.

«Mirai means "future" in Japanese — representing the project's goal of exploring what a personal operating system could become.»

---

🚀 Project Goals

Mirai OS is being developed to explore:

- Operating system architecture
- Boot processes
- Kernel development
- Low-level programming
- Memory management
- Hardware interaction
- File systems
- Command-line interfaces
- System processes
- OS development tools and workflows

The project is primarily focused on learning, experimentation, and building a deeper understanding of how operating systems work internally.

---

🛠️ Development Environment

Mirai OS was developed using:

- Windows
- WSL (Windows Subsystem for Linux)
- Ubuntu
- Git
- Linux development tools
- Terminal-based development workflow

WSL provides a Linux environment directly inside Windows, making it possible to use Ubuntu's development tools while working from a Windows machine.

🔧 Building Mirai OS

Clone the repository:

git clone https://github.com/YOUR-USERNAME/Mirai-OS.git
cd Mirai-OS

Open the project inside your WSL Ubuntu environment and install any required development tools.

If the project uses a Makefile, build it with:

make

The resulting files can then be used with the project's selected emulator or testing environment.
